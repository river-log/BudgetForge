# BudgetForge Typography

Typography is one of BudgetForge's strongest branding tools.

It should communicate confidence, clarity, and professionalism.

The interface should feel calm and readable rather than dense or decorative.

---

# Primary Typeface

## Geist

Geist is the primary typeface for BudgetForge.

Reasons for selection:

- Modern
- Highly legible
- Excellent UI readability
- Optimized for digital interfaces
- Minimal personality that allows the product to stand out

Use Geist for:

- Headings
- Navigation
- Buttons
- Forms
- Cards
- Dashboard
- Marketing pages

---

# Monospace Typeface

## Geist Mono

Used only when displaying:

- IDs
- Code
- Technical information
- Import / Export data
- CSV previews

# Alignment

Left aligned by default.

Avoid centered paragraphs.

Use centered text only for:

- Empty states
- Splash screen
- Onboarding
- Marketing hero sections

---

# Design Principles

Typography should establish hierarchy before color.

Good spacing is more important than large font sizes.

Readable interfaces create confidence.

Consistency creates trust.
