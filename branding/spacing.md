# BudgetForge Spacing System

BudgetForge uses an 8-point spacing system.

Every layout should align to this scale.

Consistency creates rhythm.

Rhythm creates clarity.

# Philosophy

Whitespace is intentional.

Every gap should have a reason.

Avoid arbitrary values.

If a value is not on the spacing scale, question why it exists.
