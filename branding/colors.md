# BudgetForge Color System

The BudgetForge color system is designed around clarity, trust, and progress.

Colors should reinforce hierarchy, communicate status, and reduce visual noise.

---

# Primary Colors

## Forge Slate

Primary brand color.

Used for:

- Logo
- Navigation
- Headlines
- Icons
- Primary UI elements

Hex

```text
#1E293B
```

---

## Forge Green

Represents progress, success, and growth.

Used for:

- Growth indicators
- Positive balances
- Savings
- Success states
- Charts
- Primary accent

Hex

```text
#22C55E
```

# Design Rules

Use color with purpose.

Never rely on color alone to communicate information.

Avoid decorative gradients.

Favor contrast over saturation.

Maintain accessibility standards.

The interface should feel calm and intentional.

---

# Brand Principle

Forge Slate creates trust.

Forge Green represents progress.

Everything else supports those two colors.
