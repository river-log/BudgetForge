# 💰 BudgetForge OS

A modern personal finance dashboard built with **React** and **Vite**.

BudgetForge OS is designed to help users organize bills, monitor monthly finances, and eventually manage savings, debt, reports, and budgeting from one beautiful dashboard.

---

# ✨ Features

## Dashboard
- Personalized greeting
- Financial overview
- Dashboard widgets
- Monthly income
- Upcoming bills
- Quick statistics
- Recent activity

## Bills
- Add bills
- Delete bills
- Mark paid
- Search bills
- Filter paid/unpaid
- Live statistics

## User Experience
- Aurora UI
- Glassmorphism
- Responsive layout
- Toast notifications
- Sidebar navigation
- React Router
- Local Storage persistence
