# 💰 BudgetForge OS

A modern personal finance dashboard built with **React**, **Vite**, and a beautiful widget-based interface.

BudgetForge OS helps users organize bills, monitor monthly finances, and manage their personal budget through a fast, modern, desktop-inspired interface.

---

# ✨ Features

## 🏠 Dashboard

- Personalized greeting
- Monthly income overview
- Quick financial statistics
- Upcoming bills widget
- Recent activity panel
- Beautiful Aurora UI

---

## 💳 Bills

- Add new bills
- Delete bills
- Mark bills as paid
- Live bill search
- Paid / Unpaid filtering
- Bills summary dashboard
- Total Due calculation

---

## 🎨 User Experience

- Aurora gradient theme
- Glassmorphism interface
- Responsive dashboard layout
- Sidebar navigation
- Toast notifications
- Local Storage persistence
- Modern desktop-inspired UI

---

## ⚙️ Built With

- React 19
- Vite
- React Router
- Lucide React
- CSS3
- Local Storage API

# 🛠️ Getting Started

Clone the repository:

```bash
git clone https://github.com/river-log/BudgetForge.git
```

Navigate into the project:

```bash
cd BudgetForge
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open:

```
http://localhost:5173
```
